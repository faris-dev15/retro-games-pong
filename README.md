| Pong | Playable |

## How to play

Open `index.html` in any web browser, or play it online via GitHub Pages
(link will appear in this repo's Settings > Pages once enabled).

**Pong controls:** W / S or Up / Down arrows (or mouse / touch), Space to start and pause. First to 5 wins.
